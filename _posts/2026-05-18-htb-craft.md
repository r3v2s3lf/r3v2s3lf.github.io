**HTB Craft** is a Linux machine that starts with discovering credentials in a `Gogs` repository, exploiting an unsafe `eval()` call in the API's brew endpoint to achieve `RCE` as a Docker container, dumping credentials from a `MySQL` database, using `gilfoyle`'s credentials to access his `Gogs` SSH key and authenticate to the host, and escalating to `root` by leveraging a stored `HashiCorp Vault` root token to generate a one-time `SSH` password via the Vault `SSH` secrets engine.
