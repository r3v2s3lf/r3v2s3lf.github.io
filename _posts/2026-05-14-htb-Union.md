**HTB Union** is a Linux machine that starts with `SQL injection` on a web form, enumerating the database to read sensitive files via `MySQL` `load_file()`, recovering plaintext credentials from `config.php`, and escalating to `root` by abusing an unsanitized `X-Forwarded-For` header passed directly into a `system()` call in `firewall.php`, enabling `OS command injection` to obtain a reverse shell as `www-data`.

### Command injection
```php
$ip = $_SERVER['HTTP_X_FORWARDED_FOR'];
....
system("sudo /usr/sbin/iptables -A INPUT -s " . $ip . " -j ACCEPT");
```
The vulnerable header is `X-Forwarded-For`, because the PHP code reads `$_SERVER['HTTP_X_FORWARDED_FOR']` and passes it directly into a `system()` command `without sanitization`.
