**HTB Pov** is a Windows machine exploiting insecure ASP.NET ViewState deserialization for initial access and local privilege escalation. The attack chain starts with Nmap revealing port 80, vhost enumeration discovering `dev.pov.htb`, and LFI exposing the `web.config` with hardcoded `machineKey`/`decryptionKey` values. Using `ysoserial.net` with these keys generates a malicious ViewState payload that executes as `pov\sfitz`, where a `connection.xml` file reveals `alaading`'s password `f8gQ8fynP44ek1m3`. `RunasCs` with these credentials gets a shell as `alaading` (with `SeDebugPrivilege` enabled), and final SYSTEM access is achieved via Meterpreter process migration into `winlogon`.
